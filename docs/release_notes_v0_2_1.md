# Version 0.2.1 Release Notes

Version 0.2.1 corrects the package information displayed by PyPI and the citation metadata shipped with the project.

## Changed

- PyPI now describes the package as a set of Python tools for African language pre-processing, code-switch auditing, emotion labels, evaluation, and routing.
- `CITATION.cff` now records the current software version and release date.
- The README and documentation now identify `0.2.1` as the current release.

The Python API and command-line behaviour are unchanged from `0.2.0`.
